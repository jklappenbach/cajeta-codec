zlib 1.3.1 (tag v1.3.1), vendored from https://github.com/madler/zlib

Unmodified upstream C sources — but a SUBSET: only zlib's in-memory buffer API
is vendored. The gz* file-I/O translation units (gzclose.c, gzlib.c, gzread.c,
gzwrite.c) are omitted (the codec uses none of them, and they pull in the
configure-gated unistd/lseek path); gzguts.h is kept because zutil.c includes it.

Built static: ../build.sh (host platform) and ../cross-build.sh (all six target
triples). See ../CROSS-BUILD.md.
